# 岐黄慧鉴 - 中医体质辨识与养生参考 Web应用

## 项目简介

岐黄慧鉴是一款基于中医理论的Web健康科普应用，旨在帮助公众了解自身体质特征，获取科学的养生参考建议。本项目适用于公共卫生与健康科学学院数字设计大赛参赛作品。

## 功能模块

### 1. 体质辨识测评
- 依据《中医体质分类与判定》国家标准（GB/T 46939-2025）
- 27条标准量表自评（Likert五级计分）
- 九种体质转化分计算与判定
- 主导体质判定 + 宜食/忌食/起居/情志建议

### 2. 症状自查
- 80项症状标签分8大类勾选
- 15种常见证候加权匹配（脾气虚、脾阳虚、肾阳虚、肾阴虚、肝郁气滞、肝火上炎、痰湿内阻、湿热内蕴、血瘀内阻、气血两虚、肺阴虚、心脾两虚、风寒束表、风热犯表、食滞胃脘）
- 可解释输出：展示命中依据与置信度
- 危险信号分流：勾选红旗症状强制提示就医

### 3. 历史记录
- 基于浏览器localStorage本地存储
- 支持查看、清空历史记录
- 隐私友好：数据不上传服务器

### 4. 合规设计
- 全站禁用"诊断""处方"等医疗用语
- 常驻免责声明
- 危险信号强制就医提示
- 药食同源食材均来自国家卫健委官方目录

## 算法说明

### 体质转化分计算
```
转化分 = [(原始分 - 条目数) / (条目数 × 4)] × 100
```
- 平和质：9条题目，条目数=3
- 其他8种体质：各4条题目，条目数=4
- 判定：转化分 ≥40 → 是；30-39 → 倾向是；<30 → 否

### 证候匹配算法
```
score(证型) = Σ(命中的次症权重) / Σ(该证型全部次症权重) × 100
条件：主症至少命中1个，否则该证型不参与排序
输出：得分最高的1-3个证型 + 命中明细 + 置信度分级（高/中/低）
```

## 数据来源

1. 《中医体质分类与判定》国家标准 GB/T 46939-2025
2. 国家卫生健康委"按照传统既是食品又是中药材的物质目录"（药食同源目录）
3. 《中医诊断学》教材常见证候辨证要点
4. 《互联网诊疗监管细则（试行）》合规要求

## 使用方法

### 本地运行
1. 用浏览器直接打开 `index.html` 文件即可
2. 无需安装任何软件或配置环境

### 部署上线（推荐）
1. 注册 GitHub 账号
2. 创建新仓库，上传本项目全部文件
3. Settings → Pages → Source 选择 main 分支
4. 获得免费网址（如 https://用户名.github.io/仓库名）
5. 也可使用 Vercel / Netlify 等免费静态托管平台

## 合规声明

本项目定位为健康科普与养生参考工具，不含诊断、处方与用药指导功能。根据《互联网诊疗监管细则（试行）》规定，人工智能软件不得替代医师提供诊疗服务，严禁AI自动生成处方。本系统严格遵守上述规定。
